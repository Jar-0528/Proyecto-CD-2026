# 🌍 Más allá de las cifras: Análisis de la tasa de suicidio y sus factores asociados

## Descripción

Este proyecto tiene como objetivo analizar la evolución de las tasas de suicidio a nivel mundial y estudiar su relación con distintos factores socioeconómicos y de salud. A partir de información proveniente de múltiples fuentes, se desarrolló un proceso completo de integración, limpieza y análisis de datos para identificar patrones, tendencias y variables asociadas al comportamiento de este indicador.

Además del análisis exploratorio, se construyó un modelo predictivo capaz de estimar si un país presenta una tasa de suicidio alta o baja considerando variables como el nivel económico, el desempleo, el acceso a servicios de salud y otras características demográficas.

---

## Objetivos

- Analizar la evolución temporal de la tasa de suicidios entre distintos países.
- Estudiar la relación entre variables económicas, sociales y sanitarias con la tasa de suicidio.
- Comparar el comportamiento del indicador entre hombres y mujeres.
- Identificar patrones mediante técnicas de análisis exploratorio de datos.
- Construir y evaluar un modelo de aprendizaje automático para la predicción de tasas de suicidio.

---

## Metodología

El desarrollo del proyecto se divide en tres grandes etapas:

### 1. ETL (Extract, Transform & Load)
- Integración de múltiples fuentes de datos.
- Limpieza y tratamiento de valores faltantes.
- Homologación de variables y formatos.
- Generación del conjunto de datos final para el análisis.

### 2. Análisis Exploratorio (EDA)
- Estadísticas descriptivas.
- Visualización de tendencias temporales.
- Comparación entre países, niveles económicos y género.
- Estudio de correlaciones entre variables.

### 3. Modelado Predictivo
- Preparación de variables para Machine Learning.
- Entrenamiento y evaluación de modelos de clasificación.
- Comparación de métricas de desempeño.
- Interpretación de la importancia de las variables.
